*The purpose of this note is to know the definitions of various terms in data communication.* 

**What is data?** It's an unorganized set of values collected together for some purpose. It needs to be processed before it can be used as **Information.** And the transmission of information from one location to another is called **Communication**. In general we have two types of communication - Telecommunication, Data communication. 

Data communication deals with transporting data or information from one point to another using computer devices. Telecommunication on the other hand uses telegraph, telephone etc.

The effectiveness of Data communication depends on five fundamental characteristics.

1. Delivery (on correct destination and correct user). 
2. Accuracy of data.
3. Security (protected from accidental damage or loss while transmitting).
4. Timeliness (do it fast, do it in real-time)
5. Jitter (refers to the uneven delay of packets. Less the jitter the better)

Transmitter, receiver, devices attached to transmitter and receiver, communication channel are the components here. The data communication channel uses two types of media. A physical transmission media (Cable) or Wireless transmission media. We definite **Communication rate** or **Transmission speed** - the speed at which data travels measured in bits per seconds (bps). Depending on the transmission speeds we get three basic categories of communication channel.
1. Narrowband - ranges from 45 - 300 bps. Mainly for telegraph lines.
2. Voiceband - up to 9600 bps. 
3. Broadband - 1mil bps

**Bandwidth** defines the volume of data that can be transmitted through a communication channel.

There are three ways for transmitting data from one point to another.
1. Simplex - unidirectional. Sender -> Receiver.
2. Half Duplex - bidirectional, but on direction at a time. Sender <-> Receiver.
3. Full Duplex - bidirectional.
