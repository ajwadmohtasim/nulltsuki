7. System Design
	Steps to design a system:
		- Requirements (3-4 min)
			- Functional - what should we have?
			- Non Functional - How many users or how much speed
			- Ask questions to interviewer for clarity
		- High Level Design (5-7 min)
			- Draw Boxes - Client, Server, Database
			- Identify CORS APIs (3-4 endpoints)
			- Choose Database type - SQL vs NoSQL (with reason)
		- Deep Dive (10-12 min)
			- Pick 2-3 components to go deeper
			- Add Caching layer (Redis)
			- Add load balancer 
			- Add message queue for async tasks
			- Add CDN for statis content
			- Discuss trade offs - why I chose this over then other
		- Bottlenecks and Scales (3-5 min)
			- what if we miraculously got 10x users all of a sudden, then what?
			- Database sharding strategy
			- Horizontal scaling approach
			- Monitoring and Failure handling
